# Top AI SDR & Autonomous Sales Agents Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on AI Sales Development Representatives & Autonomous Sales Agents*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** building **AI SDRs and Autonomous Sales Agents**. These tools autonomously prospect, research leads, personalize emails, qualify prospects, run multi-channel outreach (email, LinkedIn, calls), and book meetings on your calendar with minimal human intervention.

**Examples** include Artisan (Ava), 11x.ai (Alice), AiSDR, SalesboxAI, Salesforge (Agent Frank), Reply.io (Jason AI), Gumloop, Amplemarket (Duo), B2B Rocket, and Qualified (Piper) — the category leaders. Tools listed here emphasize **agentic capabilities** (multi-step reasoning, lead research, personalized messaging at scale, objection handling, meeting booking, and CRM integration).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, local LLMs (Ollama), custom agents, full data privacy, and complete control over outreach — ideal for sales teams and developers who want to avoid high SaaS fees and retain full ownership.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects

### Dedicated AI SDR & Autonomous Sales Agent Projects

- **[SalesGPT](https://github.com/dangerlee/SalesGPT)**  
  Open-source autonomous AI sales agent framework. Handles conversation flows, lead qualification, and multi-turn outreach using LLMs.

- **[CrewAI Sales Agents](https://github.com/crewAIInc/crewAI)** (with sales templates)  
  Leading multi-agent orchestration framework. Widely used to build full autonomous SDR teams (researcher, writer, qualifier, closer agents).

- **[LangGraph Sales Agent](https://github.com/langchain-ai/langgraph)** (sales examples)  
  Stateful, controllable agent workflows for building reliable outbound sales agents with memory and human-in-the-loop.

- **[OpenSalesAgent](https://github.com/OpenSalesAgent/OpenSalesAgent)**  
  Fully open-source autonomous sales agent that prospects, personalizes emails, and manages follow-ups.

- **[Aider + Sales Workflows](https://github.com/paul-gauthier/aider)**  
  Command-line AI coding assistant extended by community for sales automation (email generation, CRM integration scripts).

- **[Auto-GPT Sales Variants](https://github.com/Significant-Gravitas/AutoGPT)** (and forks)  
  Autonomous agent framework adapted for sales tasks like lead research and outreach automation.

- **[Gumloop Open-Source Alternatives](https://github.com/search?q=gumloop+open+source)**  
  No-code / low-code agent builders for creating custom SDR workflows (many community forks and self-hosted versions).

- **[Sales-AI-Agent](https://github.com/sales-ai-agent/sales-ai-agent)**  
  End-to-end open-source AI SDR with email personalization, LinkedIn outreach simulation, and meeting booking logic.

### Additional Strong Open-Source Options

- **LangChain + SerpAPI / Tavily** templates for lead research agents.
- **n8n / Make.com self-hosted** — Workflow automation with LLM nodes for sales sequences.
- **MCP (Model Context Protocol) Sales Agents** — Emerging open implementations for connecting agents to Gmail, LinkedIn, and CRMs.
- **Hugging Face + CrewAI** sales agent examples for local LLM deployment.
- **Reply.io style open-source sequencers** using Postmark/SendGrid + LLM personalization.
- **OpenDevin** and **Devon** — General autonomous agents adaptable for sales research and outreach.
- Many community repos combining **Ollama + LangGraph + Gmail API + Apollo/ Hunter.io** for fully private SDR stacks.

**Frameworks for building custom agents**: Use **CrewAI** or **LangGraph** + **Ollama/vLLM** + email tools (Resend, Postmark) + enrichment APIs to create production-grade autonomous sales agents that run locally or on your infrastructure.
